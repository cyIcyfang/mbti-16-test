# 十六型人格測驗

免費的互動式十六型人格測驗，支援繁體中文、简体中文與 English。共 64 題（同意程度題加情境二選一題），約 10–15 分鐘完成，作答後產出：

- 類型代碼與名稱、四個向度的百分比與偏好強度
- 優勢、盲點、工作與職涯、人際與感情、成長建議
- 認知功能圖與四個功能（主導／輔助／第三／劣勢）說明
- 深入分析：八個功能位置（英雄到魔鬼）、功能的健康光譜、循環（Loop）、抓取（Grip）、魔鬼功能
- 作答一致性檢核：用說法相反的檢核題檢查前後是否一致
- 選做的 32 題認知功能進階測驗：八個功能分數與最吻合的類型
- 可儲存的結果圖卡（1080×1350）與文字版解析

結果頁分成五個分頁（總覽、生活與成長、認知功能、深入分析、保存與分享），方便分段閱讀。

純靜態單一 HTML 檔，不需要伺服器或建置流程，作答進度只存在使用者自己的瀏覽器。

> 本測驗依據榮格心理類型理論設計，供自我探索與教學討論使用，並非官方 MBTI®。
